## Defect found and fixed

- **NFR-12 / E-RES-01, payment gateway unreachable.** When the payment gateway could not be reached at all (an
  error rather than a decline), the server answered 500 `{"error":"internal"}`, left the card reservation as Pending
  payment and kept the bag taken. Fix in server/src/services/payment/paymentService.ts: an unreachable gateway is
  handled like a gateway that does not answer in time (`reason: "timeout"`), so the reservation is dropped, the bag is
  free again and the consumer gets 402 E-RES-01. Test: nfrVerification.test.ts. The tests can now swap the gateway with
  `setPaymentGateway` (server/src/adapters/payment-gateway/paymentGateway.ts).
